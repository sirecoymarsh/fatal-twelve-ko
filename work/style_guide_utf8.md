# Fatal Twelve 한국어 초벌 번역 가이드

## 번역 출처 계약

1. 의미 판단과 문체의 유일한 원문은 일본어 시나리오다.
2. 영어 번역문은 번역 입력, 표현 참고, 의성어 참고에 사용하지 않는다.
3. 외부 번역기·번역 API를 사용하지 않고 Codex 내부 모델로 직접 번역한다.
4. 공식 번역 리소스는 Ren'Py translation ID의 존재 여부와 구조 정렬에만 사용할 수 있다. 영어 `new` 문장은 카탈로그와 번역 패킷에 넣지 않는다.
5. 일본어의 의성어·의태어·말버릇은 일본어 문맥에서 뜻과 음감을 해석해 자연스러운 한국어로 옮긴다. 영어식 `Ba-dump`, `Whoosh`, `Tch`, `Heh` 등을 경유하거나 차용하지 않는다.

## 현재 단계와 QA 정책

- 지금은 전체 시나리오의 **1차 초벌**을 끝내는 단계다.
- 모든 항목은 `status: first_draft_unreviewed`, `qa: deferred_until_full_first_draft`로 기록한다.
- 패킷별 번역 검증·문장 교정·교차 리뷰는 하지 않는다.
- 전체 초벌이 끝난 뒤 한 번의 통합 검증에서 오역, 누락, 문체, 용어, 조사, 말투, 잔여 일본어를 함께 점검한다.
- ID 정렬, 항목 수 확인, 제어 코드 보존 확인 같은 구조 검사는 번역 검증과 별개로 수행할 수 있다.

## 기본 문체

- 서술과 린카의 내면 독백은 자연스러운 한국어 해라체를 기본으로 한다.
- 대사는 인물 관계, 감정, 장면의 긴장도에 따라 존댓말과 반말을 일본어 원문 그대로 구분한다.
- 일본어 어순을 기계적으로 따라가지 말고 의미 단위 전체를 읽은 뒤 한국어 어순으로 쓴다.
- 원문에 없는 감탄, 비속어, 설명, 성격 묘사를 덧붙이지 않는다.
- 반복, 말줄임, 더듬거림, 문장 중단, 강조용 대시는 장면의 연기 정보이므로 가능한 한 보존한다.
- `ぼく`, `私`, `ワタクシ` 등 1인칭 차이는 화자의 성격과 말투로 반영하되 문맥에 없는 성별 정보는 새로 만들지 않는다.

- 로마 숫자 `Ⅰ`~`Ⅻ`와 작품 고유 개념 표시는 원문 형식을 보존한다.

## 대사부호와 표기

- 원문 대사의 `「」`는 초벌 패킷에서 유지한다. 실제 Ren'Py 출력 형식으로 합칠 때 기존 슬롯 형식에 맞춘다.
- 일본어 전각 숫자는 의미를 바꾸지 않는 범위에서 한국어 문장 안의 반각 숫자로 옮길 수 있다.
- 말줄임표는 기본적으로 `……`, 긴 침묵은 원문의 길이를 보존한다.
- 장음·파열·비명은 영어 표기를 거치지 말고 일본어 음성과 장면에 맞는 한글 표현으로 직접 옮긴다.

## 반드시 보존할 런타임 요소

- `{rb}`, `{rt}`, `{i}`, `{b}`, `{color}`, `[variable]`, `%` 치환, 이스케이프, 개행 등 Ren'Py 제어 요소를 정확히 보존한다.
- `voice`, `show`, `play`, `python`, `with`, `nointeract`, `interact`, display tail은 번역하지 않는다.
- 번역 ID와 원문 안정 키는 표시 문장과 분리한다.
- 선택지는 표시 문자열만 번역하고 점프 대상·조건식·내부 키는 바꾸지 않는다.

## 패킷 메타데이터

- 각 항목에 일본어 원문, 한국어 초벌, source file/line, 화자, 안정 ID 또는 translation ID를 기록한다.
- `source_authority: Japanese only`, `english_reference_used: false`를 명시한다.
- 정확한 Ren'Py ID가 아직 없는 항목은 source file + source line + 일본어 원문으로 식별하고, 이후 AST 카탈로그와 구조적으로 병합한다.
