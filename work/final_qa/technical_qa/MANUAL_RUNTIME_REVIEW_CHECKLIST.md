# Fatal Twelve 한국어 패치 수동 런타임 검수 체크리스트

## 실행 계약

- 라이브 `F:` 설치본은 실행하거나 수정하지 않는다.
- 릴리스 담당자가 만든 **완전 격리 전체 게임 staging**의 `fatal.exe`만 실행한다.
- 실행 프로세스 환경에 `SDL_AUDIODRIVER=dummy`를 설정한다.
- 검수용 overlay에서 `config.sound = False`로 두고 `music`/`sfx`/`voice` mixer를 모두 `mute=True`, `volume=0.0`으로 고정한다.
- 현재 동결 입력:
  - `final_text_pipeline_result.json`: `f463f7a0088016fe5a120a67db29e71bb6405f0cbb5616138bf452e9304f3df1`
  - `render_manifest.json`: `ae58dba67939a80744c44520546816edfc5c88663d2a455229ddecc7f33401c2`
  - `scenario_strings.rpy`: `10238bccafb8528011be71c7b0f2b486b042f45991b19d04571584aaa36d5cdb`

## 사용자가 직접 확인할 항목

1. **첫 실행 기본 언어**
   - 새 격리 save/persistent 상태에서 첫 화면이 한국어인지 확인한다.
   - 일본어/영어가 한국어 번역으로 덮이지 않았는지 확인한다.
2. **환경설정 → System 언어 선택기**
   - `언어 / 日本語 / English / 한국어` 행이 겹침·잘림 없이 보이는지 확인한다.
   - 버튼의 선택 상태와 클릭 영역이 올바른지 확인한다.
3. **즉시 전환**
   - `日本語` → `English` → `한국어`를 각각 눌러 메뉴 문자열이 즉시 바뀌는지 확인한다.
   - 한국어 전환 때만 Korean font/line-breaking override가 적용되는지 확인한다.
4. **재시작 지속성**
   - 각 언어를 선택한 뒤 정상 종료하고 다시 실행해 같은 언어로 복구되는지 확인한다.
   - 특히 일본어 선택은 runtime language `None`, marker `japanese`로 유지되어야 한다.
5. **대표 UI 문자열**
   - 종료 확인: `게임을 종료하시겠습니까?`
   - 타이틀 복귀 multiline 확인: `타이틀 화면으로 돌아가시겠습니까? / 저장하지 않은 진행 상황은 사라집니다.`
   - 페이지 번호 문자열 `번호 I`~`번호 XII`
   - 저장/불러오기, 환경설정 탭, 뒤로/확인 버튼
6. **대표 시나리오**
   - 새 게임 첫 대사, 이름이 있는 대사, ruby 표기, 선택지, 숫자 포함 문장, 줄바꿈 포함 문장을 확인한다.
   - 일본어 낫표, 조사, 말투, 영문 의성어 유입 여부를 육안 확인한다.
7. **폰트/레이아웃**
   - tofu(`□`), 잘린 글자, 버튼 overflow, 비정상 줄바꿈, 전각 공백·전각 숫자가 없는지 확인한다.
8. **무음 확인**
   - 네 번의 언어 전환/재실행 동안 실제 소리가 전혀 출력되지 않는지 확인한다.

## 증거 기록

- 각 캡처에 실행 파일 절대 경로, PID, 창 제목, client bounds, 선택 언어, 시각을 함께 기록한다.
- PASS/FAIL과 사용자 코멘트를 항목별로 남긴다.
- 사용자가 FAIL을 표시한 화면은 자동 검사 PASS로 덮어쓰지 않고 수정 후 다시 수동 검수한다.
